PROJECT PROCESS

Send Data.
Receive Engineering.

Product data review, DFM, mold design and final engineering release are handled as one project flow.

  1. STEP 01

    DATA REVIEW

    Send product 3D/2D data, material, molding process, expected volume, schedule and current issues.

  2. STEP 02

    DFM / OPTIMIZE

    We review wall thickness, draft, undercuts, parting direction, ribs, bosses and other manufacturability factors.

  3. STEP 03

    MOLD DESIGN

    We create the 3D mold structure and define the required core/cavity, feeding, action, cooling and ejection systems.

  4. STEP 04

    REVIEW / CAE

    Design feedback is incorporated and CAE review is added when required for a specific molding risk.

  5. STEP 05

    RELEASE / CONNECT

    Final design data is released. If requested, tooling and molding can be connected through specialist manufacturing partners.
